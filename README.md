# Site Temdetudo

Catálogo digital responsivo com 7.500 produtos do catálogo de preços de 15/11/2026.

Inclui busca por nome ou código, filtros, ordenação, fotos selecionadas do catálogo, detalhes e lista pessoal salva no navegador. Abra `index.html` para visualizar.

A lista é apenas para consulta e não envia pedidos. Preços e disponibilidade devem ser confirmados com o fornecedor.
