# Site Temdetudo

Catálogo digital responsivo da Temdetudo Atacado, criado a partir da tabela de preços de 15/11/2026.

## Recursos

- 7.500 produtos com código, nome, preço e imagem
- Busca por nome ou código
- Filtros por categoria e ordenação
- Página de detalhes com botão “Saiba mais”
- Lista pessoal salva no navegador
- Layout responsivo para celular e computador
- Animações leves e identidade visual da Temdetudo

## Como executar

O projeto é estático. Inicie um servidor local na pasta do projeto, por exemplo:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

As imagens dos produtos estão organizadas em páginas compactadas na pasta `assets/products`, mantendo todos os itens do catálogo sem deixar o repositório desnecessariamente pesado.

> Os valores podem mudar. Confirme preço e disponibilidade com o fornecedor.
