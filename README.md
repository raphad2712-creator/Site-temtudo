# Site Temdetudo

Catálogo digital responsivo com 7.500 produtos, fotos, códigos e preços.

Todos os 7.500 produtos exibem sua foto extraída do PDF original. As imagens estão reunidas em 59 arquivos WebP compactados em `assets/`. A página inclui busca por nome ou código, filtros, ordenação, detalhes e lista pessoal salva no navegador.

Abra `index.html` em um navegador para visualizar. A lista é apenas para consulta e não envia pedidos. Preços e disponibilidade devem ser confirmados com o fornecedor.
